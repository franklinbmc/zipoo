# Zipoo

Phase 1 PWA design foundation for Zipoo.

## Current Phase

Only Phase 1 is implemented:

- PWA shell
- Welcome screen
- Login UI only
- Registration UI only
- English and Kiswahili switching
- Basic app shell service worker
- Shared design system styles

No backend, database, authentication, SaaS admin, tenant workspace, or business modules are included in this phase.
